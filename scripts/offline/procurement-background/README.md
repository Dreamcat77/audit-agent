# 采购材料后台批量解析更新

适用已完成一键安装的标准离线部署（麒麟 ARM64/x86_64，JDK17）。本包只有应用代码，不重装Python、达梦或其他软件。甲方原生ARM64环境尚未验证，执行成功后才可确认当地部署。

解压后进入 `AuditAgent_Procurement_Privacy_20261010`，执行：

```bash
sudo bash update.sh
```

入口使用其他HTTP端口时，例如8088：

```bash
sudo bash update.sh http://127.0.0.1:8088
```

成功后客户端按Ctrl+F5。多选或拖入文件夹后点一次提取即可，各文件分别处理，失败只显示在自己的记录中。单文件500MB，没有原先10份/总40MB限制；每批最多1000份，单个采购需求最多关联100份。文件字数、页数等解析资源上限仍存在，超过时只提示该文件失败，不阻止其他材料。没有采购字段会提示AI_NO_FIELDS，真正不同的项目不自动合并；这与Token是否有效是不同问题。

本版移除新建说明、“选择整个文件夹”按钮及“其他服务端材料记录”入口，文件夹拖入和本批进度保留。未关联的上传工作区材料限定上传本人查询、重试及关联，其他账号（包括管理员）不能通过该入口读取。浏览器不再持久化提取字段和原文证据，当前账号进入新版时清理旧批次缓存的这类内容；只保留上传恢复所需的元数据和标识。现有原文件、数据库结果和备份未被删除。隐藏入口不等于销毁材料，也不等于机密系统合规；保存期限、清理策略及模型处理范围须按实际保密要求确定。

上传进行时可以关闭弹窗或切换页面。全部文件上传完成后，关闭浏览器也不影响服务端任务。刷新中断尚未完成的上传时，需要重新选择同一文件继续，原操作标识保留；已保存的文件不要重复上传。后台正常运行时逐份消费DM8队列，进程意外退出的处理中任务在租约到期后恢复，默认最多等待20分钟。失败文件需要明确重试，不无限自动消耗模型调用。

脚本检查包校验和、运行环境、当前代码布局、服务健康及真实数据库约束。只扩大材料顺序（V048）和状态（V050）约束，不清库，不替换业务数据；未知/缺失表结构会停止。DDL并不假定可回滚，脚本保存约束定义及行数，部分DDL失败后保留现场，重新运行只识别自己的安全中间状态。更新前后核对原环境和Nginx文件哈希，不调整AI地址、密钥、模型名称。原后端环境变量如果显式设置了较小的HTTP上传上限，其优先级高于代码500MB默认值；Nginx需保持用户已配置的502m，本包不调整它。

日志沿用详细链路诊断，后台执行可用 `material-材料记录ID` 关联，包含保存、入队、文件读取、OCR/文本解析、分段AI调用、字段校验及DM8结果提交。日志不包含密码、Key或原始业务全文。可执行包内 `scripts/collect-ai-diagnostics.sh` 收集诊断；出现报错时把记录ID和脱敏诊断结果发回。

模型明确返回LENGTH（输出截断）时，只将失败文本段细分后重试，不重做已成功段，不丢弃末尾内容或采纳不完整JSON。每个原段最多细分5层，整个文件最多512次模型调用/15分钟；认证、限流和普通JSON格式错误不会作为截断自动重试。没有修改模型地址、Key、名称或Token设置。

每次模型输入同时限制字符数和段落数（最多6段），避免大量短段落引发输出字段爆增；长段仍按原定位符拆分，全文尾部不截掉。

个别模型用精确空对象{}表示某段没有字段，该段按无字段处理并继续后续段。整份文件均无字段仍提示AI_NO_FIELDS，不伪装为成功。非空且结构错误的返回继续拒绝，日志提供校验类型及字段位置，不输出原始内容。

脚本成功后会输出恢复记录目录。撤销代码时：

```bash
sudo bash rollback.sh /opt/audit-agent/update-backups/material-background-20261010.实际后缀
```

回滚保留扩展后的数据库约束及材料记录；旧版本不会消费QUEUED任务，需要恢复新版后继续。不要删除AUDITDB、文件存储、排队任务或原版本目录。后续更新、配置变化或恢复记录不匹配时，脚本拒绝覆盖。
