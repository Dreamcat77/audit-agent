# 合同现场问题回归材料

全部为合成数据。每次选择一个子文件夹内的全部材料一起上传到合同审核，等待八项报告；不同文件夹分批上传。

1. 正常合同及配套材料：核对项目、主体、10000元价款，以及合同与中标金额一致；不要把15000元预算当合同金额。
2. 乙方空白：乙方应为无，并提出名称未填写问题。
3. 多处金额及保证金：第一处10000元与壹万元一致；第二处20000元与叁万元不一致；500元保证金不参与合同总价大小写核对。
4. 主体全称简称：同一甲方全称、明确定义的简称和主管备注归并，不虚报多个甲方。
5. 日期空栏：一处日期完整，另一处甲方签订日期空白，应定位空栏。
6. 历史业绩干扰：历史380万元和历史甲方不能进入当前合同事实。
7. 配套协议主体：保障处属于配套保密协议主体，不能覆盖主合同主体。
8. 主体名称占位：甲方、乙方（承揽方）不是实际单位名称。
9. 四页旋转扫描：实际像素含四种方向；核对10000元、项目名称、甲乙方和末页条款。
10. 十二页混合扫描：同上，另有不同内容附录；不能以只读首几页代替完整读取。
11. 网页导出的DOC：实际HTML容器，应按真实格式读取，不能只改扩展名或加载远程资源。

可把01中的正常合同单独连续上传三次，比较项目、甲乙方、合同金额及确定性核算结论；模型措辞无需逐字相同。
