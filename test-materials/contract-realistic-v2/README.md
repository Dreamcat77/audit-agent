# 合同仿真业务材料（第二版）

这是一套供审查系统测试的仿真业务资料，沿用用户提供的10份Word模板，按10类实际采购及服务业务编写。交易、采购人、供应商、人员、账号、信用代码、电话和邮箱均为编制数据，未核实对应真实主体，不得用于付款、联络、签约或证明真实资质。品牌、标准及产品参数仅用于业务表达，不证明厂家参与该交易；名称如有重合纯属巧合。正文不嵌入TEST标签或答案提示，无伪造印章、签字或真实中标效力。域名和号码仅作格式仿真，不得实际投递、访问或拨打。

## 使用

共64个独立案例、68份输入DOCX。每个案例一个目录；同一业务的不同版本必须在独立会话中测试，不要混投。“逐案例ZIP”内为纯上传材料，每个ZIP可单独导入。“测试说明与预期”不得上传到审查系统。总包仅供下载及解压，不能作为单个项目导入。

先看“先看这10份完整合同.zip”，其中是每类业务的完整基线版本。总额从18540.00元至511560.00元，各类合同的标的、数量、价格、付款结构、技术要求、交付及验收要求不同。

01版本为字段及金额自洽的完整业务材料，不代表模板全部法律条款无风险；02为大小写相差100元；03仅首行金额相差28元；04为交付或依赖日期冲突；05为关键履行期限改为签后另议；06只植入一个贴近该业务的不利条款。另有4组合同与中标通知书跨文件对照：匹配、0.01元差异、主体不同、项目错配。

预期结果是人工设计的文档事实检查，不是已执行的应用测试。允许系统指出未人为植入的原模板风险，但应定位原文；不得把未知、待确认与已失败混同。涉及法律效力或合理性须人工复核。DOCX文本解析不代表扫描件OCR已验证。

本版替代此前带有“模拟/TEST”字样、固定十万元的第一版。文件名及正文保留业务风格；场景编号及答案仅在包外索引、目录和单独说明中。无须合并代码分支即可下载使用。
