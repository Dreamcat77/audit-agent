# 采购材料后台批量解析

材料上传与解析已分离：HTTP请求只保存文件和DM8记录，并提交QUEUED状态；独立后台worker扫描DM8队列，默认同时处理两份。文件失败只更新自己的记录，不阻止其他材料。没有采购字段仍标记AI_NO_FIELDS，不把空结果当成功；真正不同的项目保留人工核对，不自动合并。

上传窗口支持多选文件、拖入文件及递归读取文件夹，支持Chrome目录分页读取。单文件500MB，每批最多1000份；取消原10份/总40MB选择限制。单个采购需求最多关联100份材料。HTTP默认接收500MB/请求502MB，现有环境变量可覆盖；Nginx沿用用户手动设置，本次代码不修改它。解析的页数、文本长度和DOCX容器保护仍逐文件生效。

上传管理器位于登录后的应用根层级，文件引用不绑定弹窗生命周期，因此关闭弹窗或切换模块继续上传。服务端入队后不依赖浏览器会话继续解析。原操作标识、文件元数据和材料ID按账号保存在浏览器本地存储；刷新后重新查询DM8记录，不生成替代操作标识。未知上传结果保留原标识；尚未上传完整的文件需要重新选择原文件。保存记录失败时停止新上传，已经入队的服务端任务继续。

按用户要求移除新建说明、整个文件夹选择按钮和“其他服务端材料记录”入口；目录拖放及本批进度保留。本人已解析材料仍通过既有采购来源接口复用。目录操作保留相对路径来区分同名文件；刷新后通过单文件选择器继续不确定上传时，在唯一匹配情况下复用原标识，并由服务端SHA-256核对内容。多个同名不确定文件不会被静默重新生成上传标识。

上传工作区的详情、历史、操作恢复、重试、可选来源列表和创建需求的全部材料关联均限定上传本人，SYSTEM_ADMIN不绕过归属检查。DM8来源列表先按ACTOR_ID过滤再分页，详情越权和不存在统一返回404。已保存需求的审批/审查材料访问沿用现有业务权限；这不是全系统保密权限审计。浏览器持久化只保留上传恢复所需的文件元数据/操作标识/材料ID及状态，不保存提取字段和原文证据；当前账号打开新版时清理旧批次缓存中的解析内容，再通过认证接口恢复。

隐藏历史入口不会销毁原文件、DM8解析结果或备份，未增加自动清理策略；持久化仍服务于后台恢复及业务证据。机密文件的保存期限、服务器管理员权限、备份销毁及模型网关是否获准处理须按实际保密要求确定。本次不修改模型配置，不宣称实现机密系统合规或服务端加密。

进程重启后扫描QUEUED或租约到期的PROCESSING记录。正常执行每15秒续租，旧租约不能覆盖新结果；FAILED/UNKNOWN不被后台自动重试。默认租约20分钟，异常中断恢复可能需要等待租约到期。队列事实和结果都保存在DM8，不依赖Redis队列或内存状态。禁用账号的排队任务标记MATERIAL_OWNER_UNAVAILABLE。

详细日志使用材料ID关联后台保存、读取、OCR、AI分段、字段校验和结果提交；后台requestId为material-材料ID。不记录真实配置凭据或文档全文。此前26样本中模型调用成功而字段校验失败，原因包含把分段返回的局部rowKey误认为多个项目。当前只用有原文依据的项目名称/编号区分项目，允许无项目身份的补充段落合并，金额等冲突仍保留人工确认。甲方Token、网络、模型输入输出限制必须以当地日志判断，26成功不证明甲方可用。

更新使用`scripts/offline/procurement-background/update.sh`：校验完整性、原环境、数据库约束，应用受控V048/V050，创建新release后切换并验证HTTP健康、前端入口及认证。AI地址/Key/名称和Nginx配置受哈希保护。失败自动恢复代码，DDL扩展和业务材料保留；`rollback.sh`拒绝覆盖后续release或变化的配置。旧代码不消费QUEUED，代码回滚后需恢复新版才能继续排队任务。构建工具为`tools/build-procurement-background-package.py`，只包含JAR、静态资源、Python源代码和迁移/诊断工具，不包含运行环境文件或业务数据。

Chrome109交付构建在原CSS末尾追加颜色回退，保留原布局规则、字体修复和其他页面样式。构建依赖在frontend/package.json中声明，`tools/build-procurement-browser.mjs`不依赖工作区外的源码。

真实长文件复测发现模型finish_reason=LENGTH、completion_tokens=1536导致JSON截断。网关现在保留安全的finish_reason，即使JSON无法解析也能识别输出截断。材料提取只细分截断段后重试，保留所有原文字符和原定位符；已成功段不重复，不接受部分JSON。细分深度最多5、每文件最多512次调用，总预算15分钟。认证、限流、未知格式错误不会被当作截断重试。模型配置和输出Token设置均未变更。

仅按3200字符分段仍会让25个短段落进入一次调用，产生过多字段并反复截断。最终版本同时限制最多6个段落和3200字符，避免这一输入结构引发的输出膨胀；大文件依然完整扫描所有段落。长段在保留原定位符的前提下切片，不能依据某段没有字段而跳过后续段。

真实模型还会对没有相关字段的单段返回精确空对象{}。该形状等价于该段无字段，继续扫描后续段并保留此前已校验事实；全篇无字段最终仍由Java标记AI_NO_FIELDS。只接受精确空对象，不接受rows=null、未知非空对象或其他结构错误。结构错误日志含校验类型和字段位置，不包含原始输入/输出。
