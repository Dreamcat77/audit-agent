# 预算返回与历史结果更新

预算结果页顶部提供“返回”，回到原上传界面，可处理另一份或另一批材料。返回只切换页面，不删除服务端任务、解析明细、审查结果或确认记录。返回后迟到的结果读取响应不会再次跳转结果页。

“历史结果”读取现有预算历史接口，列出当前账号权限内的全部服务端记录，不限本批次、浏览器缓存、预算年度或申报部门。每页20条，可翻页查看，选中记录后使用原预算结果页查看。失败或状态待确认的记录显示原状态，不显示通过结论。读取失败显示错误，不当作没有历史记录。

预算任务和明细沿用现有 DM8 持久化，不增加数据库表或迁移。本轮不调整审查规则、上传限制或解析链路，采购和预算的成功/失败文件名清单继续隐藏。

本包是仅前端补丁，适用于已经安装 `AuditAgent_Budget_Background_20261010` 完整更新包的版本（含安装了 `AuditAgent_Material_Counts_20261010` 的版本）。解压进入 `AuditAgent_Budget_History_20261010` 后运行：

```bash
sudo bash update.sh
```

自定义端口可传入本机HTTP检查地址，例如 `sudo bash update.sh http://127.0.0.1:8088`。成功后客户端按 Ctrl+F5 刷新。

脚本验证入口版本、资源和归档完整性，备份入口并原子替换，校验全部静态资源HTTP哈希、健康和未登录401。不修改 AI 地址/密钥/模型名称、Nginx、后端、环境配置或业务数据，不重启服务。未知入口版本停止覆盖。

回滚使用本次更新输出的入口备份目录：

```bash
sudo bash rollback.sh /opt/audit-agent/frontend-backups/material-simple-20261010.实际后缀
```

甲方 ARM64 浏览器实机效果为 NOT VERIFIED。
