# 智能采购自动审查三期：执行与证据契约

基线：二期源码哈希已匹配；三期前完整备份见外层 .backups/automatic-case-phase3-20261027-040540。原业务数据库不写入，自动入口仍默认关闭。

本轮仅增加 AuditCase 智能体预审与 F10 招标合规自动执行，保留询比价；不调用需要正式 Project ID 的旧入口，不以 caseId 冒充 projectId。

输入：可信结构化事实、按分析目标选择的原文片段、服务端生成的证据目录。技术需求表无需形成固定技术字段即可参与 F10。单模块记录输入摘要、文档范围、覆盖范围和证据校验结果。模型仅返回证据 ID，服务端从本案件原文重建证据；跨文件矛盾至少引用两份文件。缺失资料仅描述当前上传范围，计划不视为已完成，预算/成交/已付分别处理。

执行：询比价确定性计算；预审确定性核对后补充跨文件语义；F10 复用现有规则目录与文本匹配能力后补充语义。模块 PENDING -> RUNNING 在模型调用前持久化；中断后 RUNNING -> UNKNOWN，不盲目重放。单模块异常不阻止其他模块。仅当所有已接入模块执行完整且文件完整时案件才能 COMPLETED。NOT_EXECUTED 不表示审查通过。

持久化：优先复用 AUDIT_CASE 的 CLOB 快照与已存在四表；Report 增加兼容旧 JSON 的模块明细，不增加技术要求固定字段，不修改原业务表。

验收：分别记录 Mock、真实模型、真实隔离 DM8、HTTP 与浏览器结果；真实执行前均为 NOT VERIFIED。不得以 build 或模拟测试替代实际平台验收。
