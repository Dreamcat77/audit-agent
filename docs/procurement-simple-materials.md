# 采购材料简化界面更新

新建采购需求的材料区仅显示选择/提取操作、成功/失败/处理中数量，以及成功文件、失败文件两组简短文件名。文件名自然换行，不增加内部滚动区域。去掉刷新进度、重试按钮、逐文件原因和记录ID、已选择文件清单及已接收材料清单。进度自动更新，目录拖放、后台解析、单文件失败继续和自动填表仍可使用。

“保存草稿”改为“清空填充”：清空本次选择、材料关联、处理结果及所有表单字段，方便开始另一份需求。解析中也可以清空；未发送的旧文件停止上传，旧请求晚返回不会填入新需求。尚未确认的旧操作标识保留在本人浏览器的恢复记录中，服务端已保存材料及后台任务保留。此操作清空当前新建工作区，不删除已保存的采购业务数据或服务端原文件。

本包仅含前端，适用于之前的采购后台解析最终版或采购材料隐私修订版。未知前端版本会停止覆盖。请先解压进入`AuditAgent_Procurement_Simple_20261010`再执行：

```bash
sudo bash update.sh
```

自定义HTTP入口端口可传入本机检查地址，例如`sudo bash update.sh http://127.0.0.1:8088`。成功后客户端按Ctrl+F5刷新。脚本备份原入口、校验原版本资源，新增带哈希的静态资源，原子替换入口并检查HTTP资源、系统健康及未登录401。不重启服务、不调整Nginx或AI地址/密钥/模型名称。

回滚使用更新输出的入口备份路径：

```bash
sudo bash rollback.sh /opt/audit-agent/frontend-backups/material-simple-20261010.实际后缀
```

脚本拒绝覆盖后续已变化的入口；原静态资源保留供回滚使用。甲方ARM64浏览器尚未实机验证。
