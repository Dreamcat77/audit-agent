# 原文件证据预览与坐标高亮验收（2026-11-09）

## 本轮变化

预算、采购、合同的自动分析结果共用原文件证据预览。PDF及图片展示上传原文件渲染的像素，透明多边形只叠加在实际记录的文字位置上；可切换到解析文字对照。没有可靠坐标时仅定位页面或浏览原文件，不用相同词语或邻近段落伪造精确高亮。Word仍使用解析文字，未在本轮引入未经ARM64验证的转换器。

OCR将识别区域、置信度、原图坐标与解析结果一起传递。旋转及倾斜纠正后的区域转换回原图位置；Java规范化换行、长段拆分和UTF16位置转换保留映射。坐标索引是派生文件，绑定文档ID、原文件SHA256和冻结文本SHA256，复用文件存储，不增加数据库表。索引损坏、缺失或身份不符不丢弃可用正文，也不发布猜测坐标。

金额、日期的低置信区域有界复读：每页最多两处，并限制裁剪像素。复读不一致的事实不能继续作为确定金额计算或已证实业务错误。此措施不能保证发现所有OCR错误，用户仍应以原文件画面核对。

原页接口验证模块内文件归属及上传者权限，核对原文件大小和SHA256；两路渲染、临时文件、限制输出像素，响应禁止缓存。GET不调用OCR/模型，不修改历史业务结果。页导航、75%—200%缩放、高亮定位和关闭清理共用实现。弹窗Header与Body独立，滚动仅在正文区域内。

另修复采购正文边界：不得把“不得以历史业绩金额作为本次报价”这种要求句识别为历史章节标题，否则后面的当前招标条款和投标报价会一起被排除。真实历史业绩章节仍排除，到当前报价标题恢复。
