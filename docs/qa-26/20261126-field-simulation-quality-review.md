# 2026-11-26 现场形态留出测试复盘

## 范围

本轮使用 `test-materials/field-simulation-20261126-r3` 的独立合成留出材料，按现场描述混合 DOCX、PDF、XLSX，并覆盖预算明细、财政下达、竞争性磋商、代理协议、合同正文、价款明细表、中标通知书和廉洁保密协议。材料不含甲方真实内容；文件关系和金额真值只保存在 manifest 中。

26 原始基线批次：

- `F26B44` 预算：4 份材料，处理 468.5 秒，明细和申报/下达差异正确。
- `F26P24` 采购：4 份材料，处理 271.7 秒，预算、最高限价、报价和超限价正确；国库/自筹资金构成没有进入结果。
- `F26C24` 合同：4 份材料，处理 331.7 秒，八大项均有内容，大小写金额差和中标金额差正确；价款明细表合计差异没有形成确定性核对，两个支持材料的报告覆盖显示为 0。

## 本轮修复

1. 采购字段提取增加原文标签兜底：从同一解析片段中识别“国库资金/自筹资金”及人民币金额。只接受原文可验证、金额可解析且标签角色明确的值，不替代模型的其他字段，也不重复累计预算总额。
2. 合同价款明细表识别补充现场常见列名“分项金额”“分项价款”“项目金额”，继续要求数量、单价、金额、合计行和合同价款范围同时成立，才执行 `F02_LINE_SUM_MATCH`。
3. 合同结果覆盖统计把“有有效事实但个别引用被拒”的 `PARTIAL` 片段计入已处理字符数；`fullyReviewed` 和最终完整覆盖判定仍使用严格规则，不会把部分审查显示成完整审查。
4. 修正两个浏览器夹具：证据组件按实际 `section[aria-label]` 定位；测试服务器正确解码 esbuild 字节输出；Office 夹具不再对不负责 PDF 页图的 Office 视图断言旋转。
