# 预算材料批量后台处理更新

预算上传沿用原页面布局。支持多选Excel（xls/xlsx）和文本型PDF、递归文件夹拖放，单文件500MB；逐份处理，损坏文件不会阻断其他文件。上方简要显示成功、失败文件名和数量，多份成功材料通过一个下拉框切换原结果页，不增加重试、刷新、文件原因或滚动清单。

上传过程中可切换模块，但需保持浏览器打开；文件上传完成后即使关闭浏览器，服务端仍继续处理。再次进入或刷新会用原操作身份恢复进度。预算年度、部门在提交时固定，不因页面后来修改筛选项而改变。成功指材料已解析并生成本轮预算校验结果；既有预算金额规则及异常人工确认保留，某份材料待确认不会阻塞其余文件。本次不新增扫描件OCR或DOCX预算解析能力。

解压进入`AuditAgent_Budget_Background_20261010`后运行`sudo bash update.sh`。端口不是80时传入本机地址，如`sudo bash update.sh http://127.0.0.1:8088`。更新只包含Java后端、前端和新增预算后台队列表，不包含环境配置、业务数据、AI源代码或模型配置。新增表预检、应用代码备份、哈希和HTTP检查自动执行，仅重启Java后端。更新前按原运维流程保留数据库备份。

失败时脚本恢复原代码，保留文件和预算队列。需要手动回滚时执行`sudo bash rollback.sh 更新输出的恢复记录目录`；队列表不删除，待处理任务在重新更新至本版本后继续。后续版本变化后脚本拒绝盲目回滚。

测试材料均为合成数据，不代表真实预算批复；出现未匹配或待确认是原预算规则的正常结果。甲方ARM64实际浏览器和本地模型调用仍需现场核验，不以测试机结果替代。
