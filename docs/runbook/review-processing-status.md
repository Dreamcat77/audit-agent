# 统一审查等待态

日期：2026-11-06。范围：采购、预算、合同的主要结果等待区域，以及采购项目审查、招标材料读取和预算材料处理提示。没有更改 API、任务状态、轮询间隔、上传幂等、结果持久化或浏览器兼容方案。

## 组件与展示规则

公共组件为 `frontend/src/components/status/ProcessingStatusCard.tsx`，全局样式为 `frontend/src/styles/processing-status.css`。

```tsx
<ProcessingStatusCard
  title="正在分析材料"
  description="系统正在提取文件内容并执行审查，请稍候。"
  variant="compact"
/>
```

- `default` 用于独立加载区；`compact` 用于结果标题右侧或行内状态区。
- 采用浅灰背景、柔和边框、适度圆角、统一间距和暖色转圈图标。不依赖新增动画库，不显示模拟百分比或预估完成时间。
- 组件只负责展示，由调用方根据已知的加载/处理状态决定是否渲染。失败、未知、待核实不得仅因“没有结果”而显示无限转圈。
- 状态区域使用 `role="status"`、温和播报和完整文案；图标对辅助技术隐藏，支持减少动画设置。

## 接入范围

| 页面 | 等待态处理 |
| --- | --- |
| 采购批次自动审查 | 上传、排队、分析在标题右侧显示同一紧凑卡片；处理中隐藏结果占位、材料操作区及已打开的提取内容。终态恢复原结果、提取内容和原文件入口 |
| 采购历史列表 | 首次读取时显示状态卡，避免把正在加载显示成空列表 |
| 预算文件结果 | 处理中只显示项目标题与状态卡；完成后恢复结果和导出入口 |
| 预算材料工作区 | 批次处理中、读取结果复用同一组件；终态提示保持原有含义 |
| 合同自动分析 | 读取记录、读取结果及分析等待区复用组件；处理完成后展示审查模块与原文操作 |
| 采购项目审查 | 材料处理与读取已有结果复用组件 |
| 招标材料面板 | 加载和分析时显示统一卡片，暂不展示逐文件的未完成内容 |

处理中结果只暂时隐藏，仍由原服务保存、轮询和恢复。组件不产生网络请求，也不提供“提取内容”“原文件”等操作槽位。上传百分比仅在原上传回调提供了有效字节总量时展示。
