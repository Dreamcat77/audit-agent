## Compatibility scope

Spring Boot 3.5.16 was selected to avoid moving the initial baseline to a newer major framework line before external container requirements are known. This selection does not demonstrate or imply compatibility with TongWeb 7 or any other TongWeb version.

- TongWeb: **NOT VERIFIED**
- TongRDS: **NOT VERIFIED**
- TongHttpServer: **NOT VERIFIED**

The current packaging and runtime mode is executable JAR-first. A separate compatibility spike is required after exact TongWeb media and versions become available.

MyBatis Spring Boot integration, Spring Data Redis, Spring Session Data Redis, and Micrometer's OpenTelemetry tracing bridge are present. The DM JDBC driver remains deferred until approved media and coordinates are available. The `local` profile explicitly excludes JDBC and Redis auto-configuration, uses in-memory adapters and Servlet memory Session, and therefore remains runnable without DM8 or Redis.

## Profile activation

Profile status: **EXPLICIT ACTIVE PROFILE REQUIRED**.

The application has no default active profile. Startup requires one of `local`, `dev29`, or `customer`; otherwise the application fails with a clear guard error. Local startup is:

```powershell
java -jar target\audit-backend-0.1.0-SNAPSHOT.jar `
  --spring.profiles.active=local
```

The Fake/InMemory/Mock adapters are enabled only by `local`.

## Windows Wrapper note

The Wrapper files were generated by the official Maven Wrapper 3.3.4 plugin. Its generated `mvnw.cmd` directly indexed the optional `FileSystemInfo.Target` property, which is null for a normal directory under Windows PowerShell 5.1. The repository script contains a minimal null guard for that property so the required PowerShell 5.1 baseline can execute the wrapper. Distribution selection and download behavior are unchanged.

Maven Wrapper Unix executable bit: **PENDING MANUAL GIT INDEX STEP**.

Before commit, a human reviewer must run the documented index commands in the delivery evidence and verify mode `100755` for `backend/mvnw`. This Round did not alter the Git index.
